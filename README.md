# 🛒 Bhavani Store Sales Dashboard | Microsoft Excel

## 🎯 Project Objective
The objective of this project is to analyze Bhavani Store sales performance and identify sales trends, profitability, product performance, and regional insights to support data-driven business decisions.

## 📊 Dataset Description
The dataset contains sales transaction records, including order details, sales amount, profit, discounts, product categories, customer information, payment methods, and delivery details.

# 📈 Dashboard Features
## 📌 Key Performance Indicators (KPIs)
- Total Orders
- Total Sales
- Delivered Orders 
- Pending Orders
- Average order Value
- Cancelled orders 
- Delivery Success Rate (%)

## 📈 Charts
- Orders VS Sales
- Orders: Age Vs gender
- Sales: Top 5 States
- Sales: Men Vs Women 
- Order Status
- Orders:Channel
  
Interactive Slicers
- Month
- Channel
- Category

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers
- Data Analysis
